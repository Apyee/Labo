## Notes

- Some skills here share a name with skills already available at the user or plugin level
  (e.g. `brand-guidelines`, `canvas-design`, `docx`, `pdf`, `pptx`, `xlsx`, `skill-creator`,
  `mcp-builder`, `claude-api`, `ui-ux-pro-max`). Project-level skills take precedence here.
- `mattpocock/skills` groups skills into category folders upstream (`engineering/`,
  `productivity/`, `misc/`, `in-progress/`). They are flattened here because Claude Code
  discovers skills exactly one level below `.claude/skills/`. The upstream `deprecated/`
  category was not installed.
- `JuliusBrussee/caveman` also ships a `plugins/caveman/` bundle upstream repeating a subset
  of these skills; the standalone `skills/` directory was installed instead.
- `nuxt/ui` and `nextlevelbuilder/ui-ux-pro-max-skill` are product repositories that ship
  skills alongside their source; only their skill directories were vendored.
